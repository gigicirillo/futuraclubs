# Futura Clubs — Virtual tour

Aprire `index.html` in un browser moderno. Pagina autonoma: foto incorporata, nessuna dipendenza da servizi esterni per il tour.

- Visuale sferica navigabile tramite trascinamento, frecce e zoom.
- Panoramica introduttiva lenta: la scena scorre da destra verso sinistra per 18 secondi.
- L'animazione si ferma alla prima interazione e rispetta la preferenza di movimento ridotto.
- La fotografia è stata ritoccata con AI per ridurre gli errori di giunzione: alcune aree sono ricostruite.

`src/tour.html` conserva il frammento sorgente modificabile. `index.html` è la pagina completa pronta per un hosting statico o GitHub Pages.

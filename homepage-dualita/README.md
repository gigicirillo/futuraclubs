# Homepage Futura — Energia ed equilibrio

Anteprima autonoma della nuova homepage. Aprire `index.html` in un browser oppure visitare `/homepage-dualita/` quando la repository è pubblicata con GitHub Pages.

- Lente trascinabile con mouse e touch; frecce della tastiera quando il controllo è selezionato.
- Selettore Energia / Equilibrio, riflessi e movimento dello sfondo.
- Layout responsive e rispetto della preferenza di movimento ridotto.
- Immagine illustrativa generata con AI: non rappresenta fotografie delle strutture reali.
- Font caricati da Google Fonts; il resto della pagina non richiede dipendenze.

Il tour virtuale nella homepage principale della repository rimane separato.
